КАТАЛОГ МАКЕТОВ САЙТОВ: 12 типов бизнеса × 15 разных конструкций = 180 сайтов.

С чего начать:
1. Открой index.html в браузере. Это страница «Укажите ваш магазин».
2. Выбери тип, например барбершоп. Откроется barber.html с 15 вариантами.
3. Нажми на макет: он откроется на весь экран. «Скачать» даёт готовый файл.

Файлы:
- index.html            выбор типа магазина
- <тип>.html            страница одного типа, например barber.html
- catalog.html          то же самое одним файлом (удобно открывать на телефоне)
- sites/<тип>/<номер>/index.html   сам сайт, готов к правке и загрузке

Как сделать сайт под магазин:
1. Открой sites/<тип>/<номер>/index.html в блокноте.
2. Поменяй данные в блоке CONFIG вверху: название, телефон, адрес, услуги и цены.
3. Открой файл в браузере и проверь на телефоне. Для макета сделай скриншот.
4. Для сдачи клиенту загрузи папку на бесплатный хостинг (Netlify Drop или GitHub Pages).

Важно:
- Название, цены, отзывы и вопросы в макетах придуманные. Для настоящего магазина замени
  их на его данные или очисти отзывы: reviews: [].
- Заявки в Telegram заработают, когда впишешь telegramBotToken и telegramChatId.
  Заведи отдельного бота под каждого клиента.
